# 🥊 Vanguard Combat
**Vanguard Combat** is a sophisticated, full-stack application designed for the modern combat sports enthusiast. It serves as a central hub for tracking elite athletes across multiple disciplines, including **MMA, Boxing, Kickboxing, Brazilian Jiu-Jitsu (BJJ), and Wrestling.**

By aggregating data from various external APIs and Wikipedia, Vanguard Combat provides a dynamic and visually stunning interface to explore the world of professional fighting.

### ✨ Key Features
*   **Multi-Sport Intel:** Comprehensive coverage across five major combat disciplines.
*   **Dynamic Fighter Profiles:** Automatically generated profiles featuring records, win strategies (KO/Sub/Dec), rankings, and career bios.
*   **Live Data Integration:** Fetches real-time information from Octagon API, TheSportsDB, and Wikipedia.
*   **Interactive Rankings:** Stay updated with the pound-for-pound best across different sports.
*   **Matchups & Skills:** Explore upcoming fights and detailed athlete skill sets.
*   **Premium Aesthetic:** A "dark-mode" glassmorphic UI designed for a high-end user experience.

### 🛠️ Tech Stack
*   **Frontend:** React (JSX), Vite, Vanilla CSS.
*   **Backend:** Python (FastAPI/Flask-based architecture).
*   **Data:** REST API Integrations & Concurrent Web Scraping.
